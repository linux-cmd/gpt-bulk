# GPT Bulk

Category: Productivity. Language: English. Visibility: Public.

Queue text prompts in an existing ChatGPT conversation and send them in order while you work in another tab. GPT Bulk waits for completion controls, checks the draft before submitting it, and pauses when it cannot confirm a send. Queues are saved locally per conversation. Uses the ChatGPT website and its usage limits. Keep the conversation tab open. Independent project, not affiliated with OpenAI.

Single purpose: Send user-supplied text prompts sequentially in the ChatGPT web interface.
Storage: Retains pending prompts and the minimum send state needed to recover an interrupted submission.
Host access: The extension runs on chatgpt.com to inspect the current conversation, verify completion, and submit the prompts users queue.
Remote code: None.
Privacy policy: https://gpt-bulk.vercel.app/privacy
Support: https://github.com/linux-cmd/gpt-bulk/issues
