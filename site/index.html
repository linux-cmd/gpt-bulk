DESKTOP BROWSERS

Get GPT Bulk running.

Chrome, Edge, Brave and Opera support manual installation. Firefox supports temporary installation from about:debugging.

  1. Download and extract the ZIP.
  2. Open your browser’s extensions page and enable Developer mode. Choose Load unpacked and select the extracted folder.
  3. Refresh ChatGPT, open an existing conversation, then add your prompts and select Start.
